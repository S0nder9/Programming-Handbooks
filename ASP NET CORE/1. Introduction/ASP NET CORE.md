## ASP.NET Core

ASP.NET Core — это современный веб-фреймворк, основанный на платформе .NET Core, предназначенный для создания веб-приложений и API.

---

## Клиент и сервер

В веб-разработке всегда участвуют две стороны:

- **Клиент** — приложение или браузер, который отправляет запрос (например, Chrome, мобильное приложение).
- **Сервер** — приложение, которое обрабатывает запрос и возвращает ответ.

---

## HTTP-протокол

Для общения клиента и сервера используется протокол **HTTP (HyperText Transfer Protocol)**.

### Основные понятия:

- **HTTP-запрос (request)** — сообщение от клиента к серверу с просьбой выполнить действие (получить данные, отправить данные и т.д.).
- **HTTP-ответ (response)** — сообщение от сервера к клиенту с результатом выполнения запроса.

---

## Как работает обработка запроса

1. Сервер получает HTTP-запрос и **понимает его содержимое** (маршрут, параметры, тело запроса).
2. После этого выполняется **бизнес-логика приложения** (обработка данных, работа с базой данных и т.д.).
3. Затем формируется **HTTP-ответ**, который возвращается клиенту.
