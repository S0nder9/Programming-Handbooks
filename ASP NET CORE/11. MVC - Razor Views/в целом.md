# Razor Pages

**Razor Pages** — это подход к созданию веб-приложений в ASP.NET Core, в котором каждая страница (`.cshtml`) имеет собственный файл с логикой (`.cshtml.cs`).

Он предназначен в первую очередь для сайтов с HTML-интерфейсом и является альтернативой MVC.

---

# Идея Razor Pages

Вместо того чтобы создавать:

```
Controller
      ↓
View
```

вся логика конкретной страницы находится рядом с ней.

Например:

```
Pages/
│
├── Index.cshtml
├── Index.cshtml.cs
│
├── Employees/
│   ├── Details.cshtml
│   └── Details.cshtml.cs
```

Каждая страница представляет собой самостоятельную единицу.

---

# Как работает

Пользователь открывает

```
GET /Employees/Details
```

ASP.NET Core автоматически найдёт

```
Pages/Employees/Details.cshtml
```

и выполнит код из

```
Details.cshtml.cs
```

После этого сгенерирует HTML.

---

# Структура страницы

## Представление

```html
<!-- Details.cshtml -->

<h1>@Model.Title</h1>

<p>Hello Razor Pages!</p>
```

---

## Код страницы

```csharp
// Details.cshtml.cs

using Microsoft.AspNetCore.Mvc.RazorPages;

public class DetailsModel : PageModel
{
    public string Title { get; set; }

    public void OnGet()
    {
        Title = "Employee Details";
    }
}
```

Когда пользователь открывает страницу:

```
GET /Employees/Details
```

вызывается

```csharp
OnGet()
```

---

# PageModel

Вместо контроллера используется класс

```csharp
PageModel
```

Он играет роль контроллера именно для одной страницы.

Например

```csharp
public class IndexModel : PageModel
{
}
```

---

# Методы обработки запросов

В Razor Pages используются специальные методы.

### GET

```csharp
public void OnGet()
{
}
```

---

### POST

```csharp
public IActionResult OnPost()
{
}
```

---

### PUT

```csharp
public IActionResult OnPut()
{
}
```

---

### DELETE

```csharp
public IActionResult OnDelete()
{
}
```

Название метода определяет HTTP-метод, который он обрабатывает.

---

# Передача модели

Можно объявить свойства:

```csharp
public class IndexModel : PageModel
{
    public string Message { get; set; }

    public void OnGet()
    {
        Message = "Hello!";
    }
}
```

В Razor:

```html
<h1>@Model.Message</h1>
```

---

# Получение параметров

Из маршрута

```csharp
public void OnGet(int id)
{
}
```

или

```csharp
public void OnGet(int id, string name)
{
}
```

Работает обычный Model Binding.

---

# Работа с формами

Например

```html
<form method="post">
    <input asp-for="Name" />
    <button>Save</button>
</form>
```

Код страницы

```csharp
public class IndexModel : PageModel
{
    [BindProperty]
    public string Name { get; set; }

    public IActionResult OnPost()
    {
        return Page();
    }
}
```

`[BindProperty]` автоматически связывает поле формы со свойством класса.

---

# Routing

Для страницы

```
Pages/About.cshtml
```

маршрут будет

```
/About
```

Для

```
Pages/Employees/Details.cshtml
```

маршрут

```
/Employees/Details
```

Обычно дополнительные маршруты даже не нужно писать.

# MVC vs Razor Pages

## MVC

```
Controller
        │
        ▼
      View
```

Нужно создавать:

```
Controllers/

Views/

Models/
```

---

## Razor Pages

```
Details.cshtml
Details.cshtml.cs
```

Вся логика страницы находится рядом с её HTML.

---

# Когда использовать?

### Razor Pages

Подходит для:

- корпоративных сайтов;
- админ-панелей;
- личных кабинетов;
- CMS;
- CRUD-приложений;
- сайтов с большим количеством отдельных страниц.

---

### MVC

Лучше подходит для:

- крупных проектов;
- сложной архитектуры;
- приложений с большим количеством повторно используемой логики;
- REST API вместе с веб-интерфейсом.

---

# Razor Pages vs Minimal API

**Minimal API**

```
Request
      │
      ▼
 Endpoint
      │
      ▼
 JSON
```

Главная цель — создание Web API.

---

**Razor Pages**

```
Request
      │
      ▼
 PageModel
      │
      ▼
.cshtml
      │
      ▼
 HTML
```

Главная цель — создание HTML-страниц.

---

# Сравнение

| Характеристика | Razor Pages | MVC |
|----------------|------------|-----|
| Основная единица | Страница | Контроллер |
| Логика | В `PageModel` (`.cshtml.cs`) | В Controller |
| HTML | `.cshtml` | `.cshtml` |
| Routing | По расположению файла | Через маршруты контроллеров |
| Лучше подходит | CRUD, формы, сайты | Крупные проекты и сложная архитектура |

---

# Итог

**Razor Pages** — это фреймворк ASP.NET Core для создания веб-сайтов, в котором каждая HTML-страница имеет собственный класс `PageModel` с логикой обработки запросов. В отличие от MVC, здесь не требуется отдельный контроллер: код и представление одной страницы находятся рядом, что делает разработку простых и средних веб-приложений более удобной и наглядной.
